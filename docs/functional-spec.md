## 1. 서비스 개요

c1oser.dev는 터미널을 닮은 여러 사람용 마크다운 블로그다. 시안이 내세우는 규칙은 세 가지다.

- **글은 파일이다.** 글 하나는 마크다운 파일(`pointer.md`) 하나다.
- **분류는 폴더다.** 글은 폴더(`~/python/`)에 담기고, 태그는 폴더와 별개로 붙는다.
- **이동은 명령어다.** `cd`, `cat`, `grep` 같은 명령어로 움직이되, 같은 일을 마우스로도 할 수 있다.

## 2. 사용자와 권한

| 사용자 | 할 수 있는 일 |
|---|---|
| 게스트 (비로그인) | 랜딩, `/help`, 로그인, 회원가입 화면만 본다 |
| 회원 | 공개 글을 모두 읽고, 자기 홈 폴더에 글을 쓴다 |

운영자 역할은 V2 시안에 없다. (8절 참고)

## 3. 도메인 규칙

### 경로

| 경로 | 뜻 |
|---|---|
| `~` | 내 홈. `/users/{내 아이디}`와 같다 |
| `~/python/pointer.md` | 내 글 |
| `/users` | 사람 목록 |
| `/users/kim/spring/security.md` | 다른 사람의 글 |
| `~/.trash`, `~/.replies`, `~/.mail` | 시스템 폴더 (휴지통, 답글, 알림) |

- 폴더는 중첩할 수 있다 (`~/python/basic/`).
- 글 파일 이름은 같은 폴더 안에서 겹칠 수 없고, 확장자는 `.md`다. 한글 이름도 쓴다 (`touch 오늘.md`).
- 파일 이름과 글 제목은 별개다. 제목은 front matter의 `title`이다.

### 저장 형식

```markdown
---
title: [제목]
tags: [포인터, 예제]
created: [날짜]
---

본문
```

### 공개 범위

| 권한 | 표기 | 뜻 |
|---|---|---|
| 644 | `-rw-r--r--` | 로그인한 누구나 읽는다 |
| 640 | `-rw-r-----` | 링크가 있는 사람만 읽는다 |
| 600 | `-rw-------` | 나만 본다 |
| — | `lrwxrwxrwx` | 다른 폴더에 둔 링크 (`ln -s`) |

읽을 권한이 없는 글은 목록, 검색, 개수, 오류 화면 어디에서도 **있다는 사실이 드러나지 않는다.** 비공개 글만 있는 폴더를 남이 열면 빈 폴더와 똑같이 보인다.

## 8. 시안과 어긋나는 점

이 문서는 아래 항목을 "가정" 열대로 두고 썼다. 1번과 5번은 [MVP 범위](mvp-scope.md) 6절에서 확정했고, 나머지는 해당 기능을 만들 때 다시 확인한다.

| # | 발견한 점 | 이 문서의 가정 |
|---|---|---|
| 1 | 캔버스 제목과 구버전 랜딩에는 "강의자료", "강의는 운영자가"가 있는데 V2 화면에는 강의 기능이 없다 | 강의자료와 운영자 역할은 범위 밖이다 |
| 2 | 회원가입은 아이디를 "글에 표시될 이름"이라고 하는데, 홈과 마이페이지에는 `[표시 이름]`이 따로 있다 | 아이디는 고유하고 바꿀 수 없다. 표시 이름은 따로 두고 기본값을 아이디로 한다 |
| 3 | 644를 "누구나 볼 수 있음"이라고 하지만 글을 읽으려면 로그인이 필요하다 | 644는 "로그인한 누구나"다 |
| 4 | 640 "링크가 있는 사람만"이 로그인을 요구하는지 나와 있지 않다 | 링크가 있어도 로그인해야 읽는다 |
| 5 | 답글 위치가 화면마다 다르다. 글쓰기는 쓴 사람의 `~/.replies/[상대]/[글이름].md`, 글 읽기는 원글 쪽 `~/.replies/pointer/reply-01.md`로 나온다 | 답글은 쓴 사람 소유이고, 원글에는 링크로 붙는다. 원글이 지워지면 함께 휴지통으로 간다 |
| 6 | 홈은 "명령어 15개"라고 하고 도움말에는 20개가 있다. `feed`, `follow`, `watch`, `reply`, `mark`, `mute`, `config`, `import`는 도움말에 없다 | 5절의 표를 기준으로 한다 |
| 7 | 새 글 명령이 `touch`인데 마이페이지 버튼은 `write`다 | `touch`로 통일한다 |
| 8 | 사람 목록의 프롬프트와 상태 바가 `~/users`로 나온다 | `/users`가 맞다 |
| 9 | 폴더 이름 변경과 이동이 없다. `mv`는 글만 다룬다 | MVP에서는 폴더 이름을 바꿀 수 없다 |
| 10 | `config` 화면, 글 읽기의 `⋮` 메뉴, 휴지통 화면, 태그 화면, 회원 탈퇴가 시안에 없다 | P0인 `config`, 휴지통, 태그 목록은 폴더 화면 레이아웃을 따라 만든다. 탈퇴는 범위 밖이다 |
| 11 | 폴더마다 색이 다른데 정하는 규칙이 없다 | 만든 순서대로 팔레트 색을 돌려 쓴다 |
